Hellcard Mod Support
=============

Welcome to the [Hellcard](https://store.steampowered.com/app/1201540/HELLCARD/) Mod Support official documentation.

This repository contains:

- Documentation - set of guides for mod creators describing how to create and modify content for Hellcard.
- Hexer Mod source - all the content for the [Hexer Mod](https://steamcommunity.com/sharedfiles/filedetails/?id=3350421454). We provide it as an example and a starting template to be modified and learned from.
- Editor executable - check [Getting started](./docs/GettingStarted.md) section for instructions on how to launch the Editor.


Documentation
--------

We've written how-to tutorials for most of the content you can create or modify in Hellcard. However, it's highly possible that we didn't cover everything. If you are stuck, take a look at the content of the base game or create an [Issue](https://github.com/ThingTrunkOfficial/hellcard-mod-support/issues).

Hexer Mod
--------

The content of the mod is located in the [Mod Hexer](./mod_hexer) directory. 

Hexer Mod contains:

- New Character Class - Hexer.
- Character Look for Hexer.
- 32 new Cards.
- 3 new Artifacts.
- New Location.
- New Monster.
- New Emoticons.
