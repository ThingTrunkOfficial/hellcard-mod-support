BCCGBlockOnSubsequentCardPlayInfluence
Visible | Local

Grants block when a specified card is played multiple times. More...

Description

This influence tracks the number of times a card with a specified tag is played during one turn. When a card with a tracked tag is played a certain number of times, the linked character gains block.

Parameters

  • Card tag
    Card tag to be tracked.
  • Card play count
    Number of times the tracked card must be played before block is granted.
  • Block value
    Amount of block granted when the condition is met.
  • Default effect
    If true, applies the default visual effect when block is granted.
