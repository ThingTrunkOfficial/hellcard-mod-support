BCCGDamageNearestMonstersInConeInfluence
Global | Visible

Deals damage in a cone towards nearest monsters at the end of monsters turn. More...

Inheritance diagram for BCCGDamageNearestMonstersInConeInfluence:

Description

At the end of monsters turn deal damage in con towards specified number (per stack) of nearest monsters. Uses Cores to add bonus damage. Cores cost is paid only once per influence execution (more stacks do not increase cost)

Parameters

  • Monster count
    Number of monsters targeted by this influences (number of cones)
  • Cone width
    The width of the cone in which monsters are affected
  • Cone length
    The radius of the cone in which monsters are affected
  • Damage
    The base amount of damage applied to each monster
  • Piercing
    If true, the damage bypasses block
  • Bonus damage value
    The additional damage applied if bonus damage cost is met
  • Bonus damage cost (cores)
    The number of cores used for bonus damage
