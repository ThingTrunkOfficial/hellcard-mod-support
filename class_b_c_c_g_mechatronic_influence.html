Inheritance diagram for BCCGMechatronicInfluence:

Description

This influence is executed at the start of the player's turn. Adds number of block (per stack) to the owner of this influence and can add additional block (per stack) using Cores. Can use base contraption logic like e.g. using resources for activation

Parameters

  • Block amount
    The base amount of block granted to the character (per stack)
  • Bonus block amount
    The additional block granted (per stack) when the owner have enough Cores
  • Bonus block: required cores
    The number of Cores required adds a bonus block.
  • Spend cores for bonus block
    If true, Cores are spent to grant the bonus block.
