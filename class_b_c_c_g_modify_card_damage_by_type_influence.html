Influence that modifies card damage based on card type. More...

Inheritance diagram for BCCGModifyCardDamageByTypeInfluence:

Description

This influence modifies the damage like BCCGModifyCardDamageInfluence.
Only affects cards of specified type. If not specified otherwise, this influence affects all characters. It also can add bonus damage on top of its damage modifications. Tag filter should contain max one tag.

Parameters

  • Card Type
    Specifies the type of card that will be affected.
  • Owner only
    If true, only the owner of this influence can benefit from the damage modification.
  • Bonus damage
    The additional damage added on top after BCCGModifyCardDamageInfluence damage calculation.
  • Bonus damage: required cores
    The number of cores required for the bonus damage to take effect.
