Description

This influence modified damage of specific cards dealt in far range. It affects only owner of the influence. It only works with arrow and quarrel tags. User can specify whether influence shpuld affect cards containing aforementioned tags.

Parameters

  • Affect Arrow
    Whether influence should affect cards with arrow tag.
  • Affect Quarrel
    Whether influence should affect cards with quarrel tag.
  • Damage multiplier
    Multiplier for damage output formula of this influence. Its' value times Counter is added to damage output.
